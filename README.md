- Responsive desktop and mobile layout
- Animated hero section and scrolling skills banner
- About section with academic background
- Interactive project showcase
- Projects featuring Java, C++, console ATM, and calculator work
- Google and Coursera AI certifications
- Email, university email, phone, and WhatsApp contact links

## Project Structure

```text
Portfolio/
├── index.html

```

The complete website is contained in `index.html`, including its HTML, CSS, and JavaScript.

## Run Locally

Open `index.html` directly in a browser, or use the VS Code Live Server extension.

You can also serve the folder with any local static server:

```bash
npx serve .
```
